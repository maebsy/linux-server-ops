부록 A1 · 꼬리 질문 대비 ①

보안 설정에 대한 질문

비밀번호 로그인은 왜 안 껐나?

미션 요구 범위(포트 · root)에 맞췄고, 세 계정은 비밀번호가 없는 잠긴 계정입니다. 다음 단계는 PasswordAuthentication no 로 키 인증만 허용하는 것입니다.

fail2ban 같은 차단은?

포트 변경이 봇 시도를 대부분 없애지만, 남는 시도는 fail2ban 으로 일정 횟수 실패한 IP 를 방화벽에서 잠시 막으면 됩니다. 이번 범위에는 넣지 않았습니다.

왜 UFW 인가?

Ubuntu 기본 도구라 추가 설치가 없고, 규칙에 주석을 달 수 있어 status 만 봐도 용도가 보입니다. firewalld 판 스크립트도 함께 두었습니다.

부록 A2 · 꼬리 질문 대비 ②

스크립트 운영에 대한 질문

cron 이 실패하면 어떻게 아나?

monitor.sh 는 경고 · 오류를 stderr 로 내고, crontab 의 >> cron.log 2>&1 로 모두 cron.log 에 남습니다. syslog 의 CRON 줄로 실행 여부도 확인됩니다.

실행이 1분을 넘으면 겹치나?

flock 잠금(.monitor.lock)으로 한 번에 하나만 순환 · 기록합니다. 다음 실행은 최대 10초 기다리고, 넘으면 종료 코드 2.

왜 Python 이 아니라 bash 인가?

미션이 쉘 스크립트를 요구했고, 서버에 기본으로 있는 도구(ss · df · awk · /proc)만으로 의존성 없이 돌아갑니다. 계산은 awk 가 맡습니다.
