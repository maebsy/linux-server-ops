# 리다이렉션 > 와 >> 실수 재현 — 덮어쓰기로 기록이 사라지는 경우
# 수집: 2026-11-09 19:10:14 KST · 호스트: agent-server · Ubuntu 22.04.5 LTS
# 방법: 임시 디렉토리(/var/log/agent-app/redirect-demo)에서 같은 명령을 3번 실행해 줄 수를 비교. 경고를 일부러 만들려고 CPU_WARN=-1(항상 경고) 사용

## ① 가장 단순한 비교 — > 는 매번 비우고, >> 는 끝에 덧붙인다
$ sudo -u agent-admin env AGENT_ENV_FILE=/etc/agent-app/agent-app.env bash -c 'for i in 1 2 3; do echo "[$(date +%T)] run $i" >  /var/log/agent-app/redirect-demo/over.log; done'; wc -l < /var/log/agent-app/redirect-demo/over.log; cat /var/log/agent-app/redirect-demo/over.log
1
[19:10:14] run 3
(exit code: 0)

$ sudo -u agent-admin env AGENT_ENV_FILE=/etc/agent-app/agent-app.env bash -c 'for i in 1 2 3; do echo "[$(date +%T)] run $i" >> /var/log/agent-app/redirect-demo/append.log; done'; wc -l < /var/log/agent-app/redirect-demo/append.log; cat /var/log/agent-app/redirect-demo/append.log
3
[19:10:14] run 1
[19:10:14] run 2
[19:10:14] run 3
(exit code: 0)

## ② crontab 에 > 를 잘못 쓴 경우 — 매분 cron.log 가 비워져 직전 경고·오류가 사라진다 (cron 대신 3번 연속 실행)
$ for i in 1 2 3; do sudo -u agent-admin env AGENT_ENV_FILE=/etc/agent-app/agent-app.env CPU_WARN=-1 MONITOR_LOG=/var/log/agent-app/redirect-demo/monitor.log /home/agent-admin/agent-app/bin/monitor.sh --no-stats --quiet >  /var/log/agent-app/redirect-demo/cron-wrong.log 2>&1; done; wc -l < /var/log/agent-app/redirect-demo/cron-wrong.log; cat /var/log/agent-app/redirect-demo/cron-wrong.log
2

[WARNING] MEM threshold exceeded (60.3% > 10%)
(exit code: 0)

## ③ 2>&1 순서 실수 — '2>&1 >> 파일' 은 stderr 를 (아직 터미널인) stdout 으로 먼저 복제하므로 오류가 파일에 남지 않는다
$ sudo -u agent-admin env AGENT_ENV_FILE=/etc/agent-app/agent-app.env /home/agent-admin/agent-app/bin/monitor.sh --bogus 2>&1 >> /var/log/agent-app/redirect-demo/order-wrong.log; echo "--- 파일 내용:"; cat /var/log/agent-app/redirect-demo/order-wrong.log; wc -c < /var/log/agent-app/redirect-demo/order-wrong.log
[ERROR] 알 수 없는 옵션: --bogus (--help 참고)
--- 파일 내용:
0
(exit code: 0)

$ sudo -u agent-admin env AGENT_ENV_FILE=/etc/agent-app/agent-app.env /home/agent-admin/agent-app/bin/monitor.sh --bogus >> /var/log/agent-app/redirect-demo/order-right.log 2>&1; echo "--- 파일 내용:"; cat /var/log/agent-app/redirect-demo/order-right.log
--- 파일 내용:
[ERROR] 알 수 없는 옵션: --bogus (--help 참고)
(exit code: 0)

$ crontab -u agent-admin -l | grep monitor.sh   # 실제 설정은 '>> cron.log 2>&1' (덧붙이기 + stderr 도 같은 파일)
