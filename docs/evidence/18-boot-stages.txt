# Boot Sequence 단계별 기록 — 단계마다 사전 점검 → 실행(시각 표시) → 단계별 실패 재현
# 수집: 2026-11-09 19:07:28 KST · 호스트: agent-server · Ubuntu 22.04.5 LTS
# 방법: 각 단계가 확인하는 조건을 실행 전에 직접 점검하고, script 로 TTY 출력을 받아 줄마다 시각을 붙여 기록 (8초 후 SIGINT)

## 사전 점검 — 앱이 각 단계에서 확인하는 조건을 먼저 직접 확인
### [1/5] Checking User Account — root 가 아닌 서비스 계정인가
$ sudo -iu agent-admin id
uid=1000(agent-admin) gid=1002(agent-admin) groups=1002(agent-admin),1000(agent-common),1001(agent-core)
(exit code: 0)

### [2/5] Verifying Environment Variables — 로그인 셸에 필요한 AGENT_* 가 있는가
$ sudo -iu agent-admin env | grep ^AGENT_ | sort
AGENT_HOME=/home/agent-admin/agent-app
AGENT_KEY_PATH=/home/agent-admin/agent-app/api_keys
AGENT_LOG_DIR=/var/log/agent-app
AGENT_PORT=15034
AGENT_UPLOAD_DIR=/home/agent-admin/agent-app/upload_files
(exit code: 0)

### [3/5] Checking Required Files — AGENT_KEY_PATH 디렉토리에 secret.key 가 있고 읽을 수 있는가 (내용은 출력하지 않음)
$ sudo -iu agent-admin bash -c 'ls -l "$AGENT_KEY_PATH"/ && test -r "$AGENT_KEY_PATH/secret.key" && echo "secret.key readable"'
total 4
lrwxrwxrwx  1 agent-admin agent-core 12 Nov  9 19:06 secret.key -> t_secret.key
-rw-r-----+ 1 agent-admin agent-core 19 Nov  9 19:06 t_secret.key
secret.key readable
(exit code: 0)

### [4/5] Checking Port Availability — 15034 를 다른 프로세스가 쓰고 있지 않은가 (출력이 비어 있으면 사용 가능)
$ ss -Hltnp 'sport = :15034'
(exit code: 0)

### [5/5] Verifying Log Permission — 로그 디렉토리에 쓸 수 있는가
$ sudo -iu agent-admin bash -c 'test -w "$AGENT_LOG_DIR" && echo "writable: $AGENT_LOG_DIR"'; ls -ld /var/log/agent-app
writable: /var/log/agent-app
drwxrws---+ 2 agent-admin agent-core 4096 Nov  9 19:07 /var/log/agent-app
(exit code: 0)
