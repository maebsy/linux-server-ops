# 경고 알림 연동 — monitor.sh ALERT_CMD → bin/alert.sh (syslog + 웹훅, 같은 경고는 10분에 1번)
# 수집: 2026-11-09 19:31:11 KST · 호스트: agent-server · Ubuntu 22.04.5 LTS
# 참고: 첫 시도에서 웹훅이 전송되지 않았다 — monitor.sh 는 env 파일을 source 만 하고 export 하지 않아 자식 alert.sh 에 ALERT_WEBHOOK_URL 이 전달되지 않았기 때문. alert.sh 가 env 파일을 직접 읽도록 고친 뒤 다시 수집한 결과이며, syslog 의 19:28 두 줄은 그 첫 시도의 기록이다.
# 방법: 공용 env 에 ALERT_CMD 와 시험용 웹훅 주소(같은 네트워크의 ops-laptop:9000 에 띄운 수신기)를 넣고 수동 실행·cron 실행 결과를 확인

## ① 설정 — env 파일에 두 줄 추가 (웹훅 URL 이 들어가므로 0640 root:agent-core 로 권한 축소)
$ cp -a /etc/agent-app/agent-app.env /etc/agent-app/agent-app.env.bak.alert && printf 'ALERT_CMD=%s\nALERT_WEBHOOK_URL=%s\n' /home/agent-admin/agent-app/bin/alert.sh http://ops-laptop:9000/hook >> /etc/agent-app/agent-app.env && chown root:agent-core /etc/agent-app/agent-app.env && chmod 0640 /etc/agent-app/agent-app.env && ls -l /etc/agent-app/agent-app.env && tail -n 2 /etc/agent-app/agent-app.env
-rw-r----- 1 root agent-core 359 Nov  9 19:31 /etc/agent-app/agent-app.env
ALERT_CMD=/home/agent-admin/agent-app/bin/alert.sh
ALERT_WEBHOOK_URL=http://ops-laptop:9000/hook
