# 수집: 2026-11-09 19:52:13 KST · 호스트: agent-server · Ubuntu 22.04.5 LTS
# 참고: 첫 시도(19:40)에서는 jail 설정의 값 뒤에 # 주석을 붙였다가 fail2ban 이 주석까지 값으로 읽어 sshd jail 이 뜨지 않았다(maxretry 무효, banaction 이 "ufw # …"). 주석을 별도 줄로 옮기고 08-fail2ban.sh 가 fail2ban-client -t 검사 후에만 재시작하도록 고친 뒤, 첫 시도의 실패 기록이 findtime(10분) 밖으로 나간 19:52 에 다시 수집했다. ④ 의 auth.log 집계 12건 = 첫 시도 6건 + 이번 6건.
